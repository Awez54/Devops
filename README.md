# My Node.js Application

## Description

This is a simple Node.js application that uses the Express framework to create a web server and the `qr-image` package to generate QR codes. The application serves a basic webpage where users can input a URL, and the server generates a QR code for that URL.

## Features

- **Web Server**: Built with Express, serving on port 8080.
- **QR Code Generation**: Uses `qr-image` to create QR codes from user input.
